# OmniContext Engineering Playbooks

These playbooks turn OmniContext from context routing into a file-based
software engineering operating system. They are designed for any LLM or coding
assistant that can read repository files.

Use the smallest relevant playbook for the active task. Do not load every
playbook by default.

| Playbook | Use |
| --- | --- |
| `planning.md` | Convert a request into requirement, scope, risks, and validation plan. |
| `implementation.md` | Execute code changes with bounded access and traceability. |
| `review.md` | Perform code review focused on defects, regressions, and missing tests. |
| `testing.md` | Select and run validation with honest reporting. |
| `debugging.md` | Diagnose failures without broad, speculative edits. |
| `refactoring.md` | Improve structure while preserving behavior. |
| `migration.md` | Handle schema, data, dependency, or platform migrations. |
| `release.md` | Prepare a change for publish, merge, or handoff. |
| `handoff.md` | Transfer context between models, tools, or human maintainers. |
