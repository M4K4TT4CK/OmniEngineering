# Migration Playbook

Use this for dependency, schema, configuration, platform, or data migrations.

## Required Plan

- Current state.
- Target state.
- Compatibility strategy.
- Rollback or recovery strategy.
- Validation plan.
- Documentation impact.

## Guardrails

- Get explicit approval for destructive data changes.
- Prefer additive, backward-compatible changes.
- Separate mechanical migration from behavior changes.
- Document manual steps and assumptions.
