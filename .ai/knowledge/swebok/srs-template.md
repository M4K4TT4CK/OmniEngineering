# Software Requirements Specification Template

Use this template for features or systems too large for a single requirement
record. Keep it concise unless a contract or regulated process requires a fuller
SRS.

- Business or user objective.
- Intended audience.

- Assumptions.
- Dependencies.

- User roles.
- External systems.
- Operational owners.

## 4. Context

- Constraints from architecture, platform, policy, or process.
