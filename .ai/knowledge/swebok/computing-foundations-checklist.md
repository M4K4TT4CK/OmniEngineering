# Computing Foundations Checklist

Use this checklist when a task depends on core computing behavior.

- Algorithmic complexity is acceptable.
- Data structure choice fits access patterns.
- Runtime, platform, or operating-system assumptions are stated.
- Concurrency or ordering risks are considered.
- Persistence, transaction, or consistency behavior is considered.
- Network timeouts, retries, or partial failures are considered when relevant.
- Resource use is bounded or justified.
- Relevant edge cases are tested or documented.
