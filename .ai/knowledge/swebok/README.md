# SWEBOK-Aligned Knowledge Packs

This folder adapts software engineering body-of-knowledge concepts into
OmniContext playbooks, templates, and checklists.

The material is written for practical project use and does not copy protected
standards text. When a project is subject to a formal standard or contract, use
the official standard as the authority and treat these files as implementation
guidance.
